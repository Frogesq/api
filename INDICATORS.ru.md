# Свои индикаторы

`combat.double_tap()` возвращает копию состояния Double Tap. Функцию можно
вызывать из `paint`; она не запускает prediction, трассировки или стрельбу.
`indicators.get("ragebot", "double tap")` возвращает ту же структуру.
Проверить поддержку можно по `api.capabilities().double_tap_snapshot` и
`api.capabilities().custom_indicators`.

`charge` — прогресс модельного восстановления от 0 до 1. `ready` не зависит от
наличия врага: это готовность окна оружия, а не найденный выстрел. При ограничении
истории/политики заряд остаётся ниже 1. `remaining` измеряется в секундах до
модельного срока, поэтому ноль сам по себе не означает готовность.

| state | Значение |
|---|---|
| off | Rage/DT выключен |
| unavailable | Нет успешно опубликованного свежего наблюдения |
| weapon_blocked | Неподдерживаемое оружие, меньше двух патронов или перезарядка |
| cooldown | Модельное восстановление ещё идёт |
| window_blocked | Время прошло, но история/политика не допускает окно |
| ready | Окно DT доступно; нужен допустимый выстрел по цели |
| committed | Опубликована команда с DT-кандидатом |

`committed` не подтверждает две серверные пули или попадание. Снимок старше
0,25 с становится `unavailable`, `available=false`, `charge=0`. Смена карты
сбрасывает наблюдение. В раннем callback команды до окончательной сериализации
состояние может быть `unavailable`; для индикаторов используйте `paint`.
Таблицы независимы от движка и безопасны для хранения, но для свежих данных
вызывайте функцию повторно. Поля и единицы описаны в [типах](TYPES.ru.md).

При открытом меню обслуживание истории DT продолжается. Индикатор читает
состояние предыдущей команды того же игрока; наведение и Lua-callback команды
при этом не запускаются. Отсутствие такой записи или ошибка записи истории/CRC
даёт `unavailable`, а не сохранённый полный заряд. В меню `committed` не создаётся.

Для других функций используйте `indicators.get(category, name)`: точные имена
берутся из `settings.list()`. Булевы настройки возвращают `kind="toggle"`,
`active` и `state="on"/"off"`. Это эффективное значение настройки с учётом
бинда, а не подтверждение действия в игре. Для отсутствующего, неоднозначного
или небулевого поля возникает обычная Lua-ошибка. Числовые значения можно
читать через `settings.get`, сведения о биндах — через `settings.binds`.

Готовый [пример](examples/custom_indicators.lua) плавно рисует круг DT и подписи
включённых функций. Стандартный круг включается пунктом **Double Tap Indicator**
рядом с Double Tap и работает независимо от Keybinds. Сглаживание касается только
рисунка: оно не задерживает стрельбу и не заряжает DT. Настройка стандартного
индикатора, как и остальные булевы поля категории ragebot, меняется в меню.

API только читает состояние; он не предоставляет команд зарядки, форсирования
выстрела или обхода проверки цели. Свободный FFI по-прежнему не является
песочницей и может изменять память независимо от ограничений обычного API.
