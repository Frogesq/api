# Трассеры и хитмаркеры

В Misc → Effects трассер включается переключателем Bullet Tracers.
Используется игровой эффект Skeet с длительностью 1 секунда; рядом выбирается RGB.
Под переключателем доступны Bloom, Bloom Radius (1–64 пикселя) и Bloom Intensity
(0–1). Это дополнительное экранное свечение по тому же маршруту; при выключении
bloom остаётся игровой эффект Skeet. Его прозрачностью управляет сам particle,
а альфа выбранного цвета влияет на дополнительный bloom. Трассеры показывают
локальные события weapon_fire и bullet_impact. У обычного оружия один выстрел
создаёт одну линию, даже при нескольких impact после пробития. У дробовиков
сохраняются отдельные лучи дроби. Свечение затухает за 1 секунду; возле камеры
его яркость уменьшается. Оно не учитывает глубину сцены.

Хитмаркер появляется после player_hurt, где атакующий — локальный игрок:
крест плавно увеличивается и исчезает. Для него доступны цвет, размер,
длительность, толщина, промежуток и собственный bloom. При выключенном или
недоступном bloom остаётся обычный крест.

Трассер и хитмаркер используют общую запись событий weapon_fire, bullet_impact и
player_hurt. При совпадении луча с попаданием конец трассера совпадает с центром
мирового маркера. При пробитии
нескольких игроков на одном луче трассер идёт через маркеры до последнего из них.
Позиция приблизительная: пострадавшая область проецируется на луч impact с допуском
32 игровые единицы от её текущего положения. Backtrack-геометрия рейджа не читается.
Если подходящего impact нет, используется доступная позиция пострадавшей области.
Если позиция недоступна, мировой маркер не создаётся. Если сохранённая точка выходит
за экран, маркер временно не рисуется, но остаётся на своём месте до истечения
длительности. После убийства он не следует за моделью и не переносится в центр экрана.
Позиция по событию урона является оценкой, а не точной серверной координатой.
Нож и гранаты также могут создавать маркеры, но не меняют линии огнестрельного оружия.
Поздний hurt создаёт маркер независимо от уже выпущенного трассера; запущенный particle
не перестраивается. Без полученного player_hurt подтвердить попадание невозможно.

Для объединения событий маркер от пули ожидает 35 мс; трассер без hurt — не менее
180 мс. Это задержка отображения, без ожидания внутри обработки команды. Они не меняют команды, prediction,
выбор цели или стрельбу. При переполнении ограниченной очереди часть эффектов
пропускается. Маркеры имеют отдельную историю на 128 записей и не зависят от очереди
трассеров. Начало луча — сохранённая позиция глаз при weapon_fire либо при первом
событии, если impact/hurt пришёл раньше. Без weapon_fire дополнительная линия не выпускается.

## Поля категории impacts

| Имя поля | Тип / единицы | Применяемый диапазон |
| --- | --- | --- |
| `bullet tracers` | boolean | Включение локальных трассеров |
| `bullet tracer color` | `{r,g,b,a}` | Компоненты 0–255 |
| `bullet tracer bloom` | boolean | Дополнительное свечение трассера |
| `bullet tracer bloom radius` | number, пиксели | 1–64; по умолчанию 3 |
| `bullet tracer bloom intensity` | number, доля | 0–1; по умолчанию 0,5 |
| `hitmarkers` | boolean | Включение мировых хитмаркеров |
| `hitmarker color` | `{r,g,b,a}` | Компоненты 0–255 |
| `hitmarker duration` | number, секунды | 0,1–3 |
| `hitmarker size` | number, пиксели | 4–20, длина луча креста |
| `hitmarker gap` | number, пиксели | 0–12, расстояние от центра до луча |
| `hitmarker thickness` | number, пиксели | 1–5 |
| `hitmarker bloom` | boolean | Bloom хитмаркеров |
| `hitmarker bloom radius` | number, пиксели | 1–64 |
| `hitmarker bloom intensity` | number, доля | 0–1 |


Пример временного цвета по общим правилам [настроек](SETTINGS.ru.md):

```lua
events.on("paint", function()
    settings.override("impacts", "bullet tracer color", {255, 120, 60, 255})
end)
events.on("shutdown", function()
    settings.override("impacts", "bullet tracer color", nil)
end)
```

Чтение через settings.get возвращает boolean/number/копию RGBA. Запись разрешена
через settings.set либо временный settings.override; числа должны быть конечными.
Bloom трассера доступен через settings.get/set/override и сохраняется в конфиге.
Имена совпадают с прежними bloom-полями, поэтому сохранившиеся старые значения
снова читаются. При интенсивности 0 дополнительное свечение не рисуется.
Поля выбора стиля, длительности и толщины трассера недоступны. Их значения
в старых конфигах игнорируются; обращение к неизвестному полю из Lua вызывает ошибку.
Пример [rgb_bullet_tracers.lua](examples/rgb_bullet_tracers.lua) работает с текущим цветом.

Старый ключ `hitmarker glow` принимается как alias для `hitmarker bloom`.
Новые settings.list и сохранения используют каноническое имя `hitmarker bloom`.

История хитмаркеров и очередь новых трассеров очищаются при отключении эффекта,
смене конфига/локального pawn, сбросе раунда/сессии и выгрузке. Смерть и временное
отсутствие локального pawn сами по себе не удаляют уже полученные попадания.
Уже выпущенный particle Skeet завершает свою длительность самостоятельно.
Повторное включение не переигрывает старую очередь.
История bloom ограничена 32 трассерами, максимум восемь сегментов на трассер.
При переполнении старое свечение заменяется новым. Bloom использует заранее
подготовленные общие графические ресурсы; это не гарантирует отсутствие GPU-нагрузки.
Изменение этих полей не предоставляет управление выстрелом или его результатом.
Произвольные FFI-записи не ограничиваются Lua API: [FFI](FFI.ru.md).
