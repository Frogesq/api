# Установка и первый скрипт

## Файлы

Откройте `%LOCALAPPDATA%\skeet` через адресную строку Проводника. Положите файл с расширением `.lua` непосредственно в эту папку, затем найдите его в списке Lua меню Skeet и включите. Код можно редактировать встроенным редактором. После изменения включённого скрипта выключите и включите его, чтобы загрузить новую версию.

Файлы `api.lua` и `ffi.lua` из документации нужны редактору для автодополнения. Не включайте их как игровые скрипты. Для установленного `example.lua` данные storage находятся в `example.lua.json`; не удаляйте этот JSON при обычном обновлении скрипта. Значения контролов ui.create и их бинды сохраняются в конфигурации Skeet, отдельно от storage: сохраните нужный конфиг через меню.

| Путь относительно `%LOCALAPPDATA%\skeet` | Содержимое |
|---|---|
| `example.lua` | Скрипт |
| `example.lua.json` | Данные storage скрипта |
| `resources` | Файлы для `render.setup_texture` и `render.setup_font` |
| `fonts` | Шрифты, указываемые как `fonts/имя.ttf` в render API |
| `skeetles` | Изображения, указываемые как `skeetles/имя.png` |
| `muzon` | Звуки, указываемые обычным именем в audio API |
| `sounds` | Звуки, указываемые как `sounds/имя.wav` |
| Корень папки | Также шрифты для `ui.set_menu_font` и `ui.set_language_font` |

У функций разные правила поиска файлов. Путь для render-шрифта нельзя автоматически переносить в настройку шрифта меню. Подробнее: [графика](RENDER.ru.md), [интерфейсы](UI.ru.md), [звук](SERVICES.ru.md).

## Рабочий минимальный пример

Сохраните код как `hello.lua`:

```lua
local visible = ui.create("checkbox", "hello_visible", "Show greeting", true)
local tint = ui.create("color", "hello_color", "Text color", {120, 200, 255, 255})

events.on("paint", function()
    if not ui.get(visible) then return end
    render.text(30, 80, "Hello from Skeet", ui.get(tint))
end)

client.log("Loaded", api.script, api.lua, api.version)
```

После включения появятся два контрола скрипта и текст на экране. `ui.create` выполняется один раз при загрузке. Обработчик `paint` вызывается повторно и только рисует текущий результат. Постоянные `id` контролов связывают их со значениями конфигурации; смена `id` создаёт другую настройку.

## Клавиша включения

Чтобы добавить переключение по F6, сразу после создания checkbox используйте:

```lua
local visible = ui.create("checkbox", "hud", "HUD", true, {key=117, mode=0})
events.on("paint", function()
    if ui.get(visible) then render.text(30, 110, "HUD", {255,255,255,255}) end
end)
```

Коды клавиш — Windows VK. `117` — F6, `118` — F7, `119` — F8, `32` — пробел. `mode=0` переключает значение нажатием; `mode=1` использует удержание. Для независимого окна его собственная клавиша задаётся отдельно.

## Если пример не появился

Проверьте расширение файла: `hello.lua.txt` не подходит. Откройте журнал Lua и прочитайте первую ошибку. Убедитесь, что checkbox включён, координаты находятся на экране и в тексте нет скопированных Markdown-ограждений. Отключите второй экземпляр того же примера с другим именем.

Сначала проверьте небольшой скрипт без FFI, затем добавляйте игровые действия. Для ручного завершения текущего скрипта существует `client.unload()`; выгрузка произойдёт после возврата из текущего callback.
