# Радар

## Штатный радар

В **Misc → Interface** включите **Radar**. **Rotate Radar** поворачивает панель по направлению камеры; **Radar X/Y**, **Radar Size** и **Radar Range** задают положение, размер и дальность. Range — расстояние от центра до края квадрата в игровых единицах. Общий ESP для радара включать не требуется.

Центральная белая точка обозначает игрока, за которым вы наблюдаете; остальные игроки также обозначаются белыми точками. Гранаты показываются кольцами. Включите **Grenade Trajectories**, **Grenade Throw Preview** и **Molotov Area**, чтобы видеть соответствующие данные и на радаре. Основные переключатели по умолчанию выключены.

Это самостоятельная панель относительно игрока, без фоновой текстуры карты и без изменения штатного HUD игры. Высота этажа не отсекается: точки на разных этажах могут накладываться. Отображаются только доступные клиенту сущности; это не получение скрытых серверных данных.

Отдельный **Reveal Radar** в **Misc → Interface** отмечает доступных клиенту игроков как обнаруженных на штатном радаре игры. Работает независимо от общего ESP и отдельной панели Radar. Он не добавляет траектории и зоны огня на карту игры. При отсутствии нужных полей schema функция пропускает записи. При отключении собственные изменения снимаются на следующем обновлении; полученные от игры новые значения не заменяются сохранёнными, если отличаются от записанных функцией.

## Собственная панель в Lua

`radar.snapshot(paths)` возвращает копию данных: map, center, yaw, players, grenades, age. Первое обращение запрашивает сбор; до следующего обновления результат может быть `nil, "snapshot_unavailable"`. Повторяйте чтение из paint, пока панель включена. Штатный Radar для Lua включать не требуется.

Без прогнозов минимальный интервал снимков — 50 мс; с траекториями — 16 мс, с предпросмотром или Lua paths=true — 8 мс. Реальная частота зависит от кадров игры и бюджета трассировок. Снимки старше 250 мс не возвращаются. Yaw берётся из актуальной матрицы вида при чтении, поэтому поворот панели не ждёт нового снимка игроков. После прекращения Lua-запросов сбор прекращается в течение 500 мс, если он не нужен штатной функции. При смене карты данные сбрасываются. В снимке максимум 64 живых игрока и 128 гранат; поля описаны в [типах](TYPES.ru.md). Игрок, вокруг которого строится радар, исключён из players. Его позиция — center.

`paths=true` дополнительно запрашивает траектории гранат от начальной позиции выпуска. Они сохраняются на время жизни наблюдения, имеют собственный возраст trajectory_age и могут отсутствовать из-за недоступности начальных данных или лимита расчётов. Это весь маршрут, а не пересчёт от текущей позиции гранаты. Для обычного радара оставьте false.

`radar.project(world, center, yaw, range, x, y, size, rotate, clamp_edge)` возвращает `screen_x, screen_y, inside`. При rotate=true верх панели соответствует направлению камеры; при false +X направлен вправо, +Y — вверх. По умолчанию обе последние опции true. inside указывает, была ли точка внутри **до** прижатия к границе. Для рисования линий используйте clamp_edge=false и ограничивайте их рамкой панели, иначе дальние сегменты будут искажаться.

Пример одной точки:

```lua
events.on("paint", function()
    local s = radar.snapshot()
    if not s then return end
    for _, p in ipairs(s.players) do
        local x, y, inside = radar.project(p.origin, s.center, s.yaw, 1500, 30, 250, 220)
        local color = {255,255,255,230}
        render.text(x, y, inside and "+" or ">", color)
    end
end)
```

Полная панель с контролами, игроками, гранатами и кэшем иконок: [radar.lua](examples/radar.lua). Можно менять цвета, форму точек, подписи, дальность и фильтровать этажи по `origin.z - center.z`. Проекция — чистая математика: её можно применять и к записанным позициям grenade helper. Для собственной текстуры карты используйте обычный render API и самостоятельно задавайте её масштаб/привязку; карта и её метаданные этим модулем не выдаются.
