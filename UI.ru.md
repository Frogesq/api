# Контролы, окна и оформление меню

Штатные `Safety Mode` и `Limiter` удалены из Skeet. Их старые значения в
конфигурациях игнорируются и не включают ограничения при загрузке конфига.

## Контролы конфигурации

Создавайте `ui.create` один раз на верхнем уровне. Возвращаемый id принадлежит текущему скрипту. Внутри него id должен быть уникальным, длиной 1–80 байт; label — до 160 байт. Лимит — 128 контролов.

| kind | default | Дополнительные аргументы |
|---|---|---|
| `checkbox` | boolean | Необязательная таблица `{key=VK, mode=0 или 1}` |
| `slider` | Число внутри диапазона | minimum, maximum; minimum < maximum |
| `combo` | Индекс от 1 | Таблица из 1–512 строк, каждая до 160 байт |
| `color` | Четыре целых RGBA 0–255 | Нет |
| `text` | Строка до 4096 байт | Нет |

```lua
local enabled = ui.create("checkbox", "enabled", "Enabled", true)
local amount = ui.create("slider", "amount", "Amount", 25, 0, 100)
local mode = ui.create("combo", "mode", "Mode", 1, {"First", "Second"})
local color = ui.create("color", "color", "Color", {255,180,80,255})
local caption = ui.create("text", "caption", "Caption", "My script")
```

`ui.get(id)` возвращает значение, `ui.set(id, value)` проверяет и меняет его. У checkbox с биндом get учитывает действующий бинд. Тип и диапазон должны соответствовать созданному контролу. Для combo используется нумерация с **1**, не с 0.

`ui.bind(id)` читает бинд checkbox; `ui.bind(id, key, mode)` назначает его. Поддерживаются toggle `0` и hold_on `1`; legacy `2` преобразуется в toggle. Клавиша `0` отключает назначение. Значения ui.create и бинды сохраняются вместе с конфигурацией Skeet. Сохраните конфиг через меню, чтобы перенести их между запусками. Обычная перезагрузка Lua в текущем процессе также сохраняет значения контролов. Storage использует отдельный файл и не заменяет сохранение конфигурации.

## Отдельное окно для этих контролов

```lua
local show = ui.create("checkbox", "show", "Show overlay", true)
local window = ui.create_window("options", "Overlay options", {
    x=160, y=160, width=320, height=220, key=117, open=false
})
ui.attach_window(show, window)
```

F6 открывает это окно независимо от главного меню. `key=0` привязывает видимость к меню Skeet. По умолчанию для key=0 окно открыто, для отдельной клавиши — закрыто. Follow-окно не станет видимым поверх закрытого меню только из-за `ui.set_window_open(id, true)`.

Размеры: ширина 180–1600, высота 120–1600 пикселей; defaults 320×360, позиция 120×120. Лимит — 8 окон на скрипт. Окно можно двигать и менять его размер.

`ui.attach_window(control, nil)` возвращает контрол на штатную страницу скрипта. `ui.window_bind(id)` читает key/open/follows_menu; второй аргумент меняет клавишу. `ui.set_window_open(id, open)` задаёт состояние. `ui.get_window(id)` возвращает текущий прямоугольник и параметры.

Для своего расположения и рисования интерактивных элементов используйте [XUI](XUI.ru.md). `ui.create_window` и `xui.create_window` используют общее пространство имён окон скрипта: не создавайте два окна с одним id.

## Мышь и положение главного меню

В `paint` доступны:

- `ui.is_menu_opened()` — открыто ли меню Skeet.
- `ui.get_menu_rect()` — `{x,y,w,h}` в экранных пикселях.
- `ui.mouse_state()` — `{x,y,down,clicked}`.

Все paint-обработчики получают один и тот же click. Проверяйте попадание в свой прямоугольник и завершайте перетаскивание при отпускании или закрытии меню. Для корректной интерактивности отдельного окна предпочтительны XUI hit-test и `xui.invisible_button`.

## Цвета, прозрачность и шрифты

Получите поддерживаемые имена через `ui.style_colors("menu")` или `ui.style_colors("xui")`. `ui.set_style_color(backend, name, color)` устанавливает override; `color=nil` снимает свой. Не угадывайте ключи цвета по подписи пункта меню.

`ui.set_blur_opacity(surface, opacity)` принимает `sidebar`, `header`, `body`, `surface`, `card`, `control` и число 0–1. nil снимает override. `ui.reset_theme()` освобождает оформление, установленное этим скриптом.

`ui.set_menu_font("font.ttf", 11)` выбирает файл непосредственно из `%LOCALAPPDATA%\skeet`; поддерживаются TTF/OTF/TTC/OTC, размер 8–24. Возвращаются success и возможная ошибка. nil вместо файла снимает свою настройку. `ui.get_menu_font()` возвращает effective language, source (`default`, `menu`, `language`), filename и size. Успешное назначение готовит настройку; создание GPU-шрифта происходит в следующем кадре меню.

Это шрифт штатного меню. Для текста Lua и игровых ESP-подписей применяются отдельные методы [render](RENDER.ru.md).

## Перевод меню

```lua
local ok = ui.register_language("example-ru", "Example Russian", {
    ["Settings"]="Настройки"
})
if ok then ui.set_language("example-ru") end
```

Словарь сопоставляет точный английский видимый текст с UTF-8 переводом. Получите допустимые ключи через `ui.get_translation_keys()`. Они не содержат служебный суффикс `##`. Отсутствующая строка отображается по-английски. Ваш собственный текст Lua, исходник и лог не переводятся автоматически.

В Misc → Language доступны English (`en`), 简体中文 (`zh-CN`, упрощённый китайский) и Português (Brasil) (`pt-BR`, бразильский португальский). Lua для выбора этих языков не нужен; выбранный ID сохраняется в конфигурации. Переводятся штатные разделы, настройки, списки, подсказки, редактор и окна подтверждения. Названия предметов из каталога CS2 используют язык игры; пользовательские имена файлов/моделей, текст Lua-интерфейса, исходники и сообщения скриптов остаются исходными.

id пользовательского языка: ASCII-буквы, цифры, `-`, `_`, 1–48 байт; name: 1–96 байт. Встроенные `en`, `zh-CN` и `pt-BR` зарезервированы. `ui.get_languages()` перечисляет сначала эти три языка, затем пользовательские по ID; `ui.get_language()` возвращает действующий id; `ui.translate(text, id)` переводит отдельную строку, по умолчанию в текущий язык. Готовые словари: [中文](menu-localization.zh-CN.json) и [Português (Brasil)](menu-localization.pt-BR.json).

Пример [menu_localization_pt_br.lua](examples/menu_localization_pt_br.lua) копирует встроенный перевод через `ui.get_translation_keys()` / `ui.translate(key, "pt-BR")` в отдельный `pt-BR-example`, позволяя менять отдельные фразы и назначать собственный шрифт. Он не заменяет встроенный `pt-BR`.

`ui.set_language_font(id, filename, size)` назначает шрифт только своему языку. Он имеет приоритет над общим menu-font override. nil снимает шрифт языка. `ui.unregister_language(id)` снимает свой словарь. При выгрузке владельца словарь удаляется, а недоступный выбранный язык отображается с fallback на English.

## Шестой раздел: специальный слот Lua

`ui.create_tab(id, title, options)` занимает шестой раздел главного меню Skeet.
**Одновременно слот может занимать только одна активная Lua**, у владельца может
быть только одна вкладка. Загрузка второй Lua, которая вызывает `ui.create_tab`,
завершается ошибкой `Lua menu slot 6 is already occupied; disable its owner first`.
Первая Lua продолжает работать. Отключение, выгрузка, ошибка владельца или
`ui.remove_tab(id)` освобождают слот. Ошибка создания не оставляет слот занятым.
Без активной Lua, зарегистрировавшей вкладку, шестая иконка скрыта и её область
не реагирует на нажатия. Если владелец выгружен при открытом шестом разделе,
меню возвращается в Config.

Рекомендуется занимать специальный слот только крупным, комплексным Lua, автор
которых предоставляет пользователю большой набор полезных функций и настроек.
Для небольших Lua лучше использовать `ui.create` на обычной странице скрипта
в меню Skeet, оставляя единственный специальный слот свободным. Собственные
окна `ui.create_window` и `xui.create_window` доступны независимо от слота.

```lua
local tab = ui.create_tab("suite", "My suite", {icon="L", active_icon="L"})
local left = ui.create_tab_group(tab, "main", "Main", 1, {top=0, bottom=1})
local right = ui.create_tab_group(tab, "style", "Appearance", 2, {top=0, bottom=1})
local enabled = ui.create("checkbox", "enabled", "Enabled", false)
ui.attach_tab(enabled, tab, left)
```

До 16 секций имеют собственные названия и прокрутку. Четвёртый аргумент группы —
колонка: 1 слева, 2 справа. Без пятого аргумента секции делят высоту своей колонки
поровну. Для собственного размещения передайте `{top=0, bottom=0.5, span=1}`:
границы задаются долями высоты области настроек, `span=2` занимает обе колонки
и разрешён только из колонки 1. Минимальная высота — 0.12, пересечения запрещены.
Все группы одной вкладки должны использовать либо автоматическое, либо явное
размещение. Создавайте группы до привязки контролов; в сгруппированной вкладке
`ui.attach_tab` требует id группы. Без групп используется одна секция на всю ширину.
Настройки также остаются доступны на обычной странице скрипта.

`icon` и `active_icon` задают текстовую иконку; `icon_texture` и
`active_icon_texture` — две собственные текстуры скрипта. Создавайте их один раз
в `paint` через `render.setup_texture*`, затем вызывайте `ui.set_tab_style`.
Активная текстура по умолчанию белая; неактивная приглушена. Подсветку можно
включить в саму активную картинку. Нулевой active texture использует обычную
текстуру; нулевой обычный texture возвращает текстовую иконку. Доступны отдельные
`icon_color`, `active_icon_color`, `background` и `active_background`.
В боковой панели рисуется иконка; заголовки секций используют штатный стиль.
Старые `text_color`/`text_colors` сохраняются как метаданные, но не рисуются.
`ui.set_tab_style(id, nil)` сбрасывает оформление, сохраняя id, название и группы.

Готовая [Lua Studio](examples/sixth_slot.lua) показывает четыре секции разного
размера, пару иконок с белой активной подсветкой, настройки HUD, анимацию и
отдельное окно на F7. Включите скрипт и нажмите шестую иконку слева. Перед
загрузкой другой Lua, использующей специальный слот, отключите демонстрацию.
