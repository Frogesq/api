# Гранаты: helper, броски и предупреждения

## Активная граната

В командном событии вызовите `grenades.context()`. Если игрок не жив или в руках не граната, результат nil. Проверяется фактическое активное оружие, включая поколение его дескриптора.

| Поле | Значение |
|---|---|
| item_id | Тип предмета: 43 flashbang, 44 HE, 45 smoke, 46 molotov, 47 decoy, 48 incendiary |
| handle | Полный дескриптор текущего оружия; хранить для сравнения, не разыменовывать как адрес |
| command_number | Номер текущей команды |
| pin_pulled | Состояние чеки, boolean или nil |
| throw_time | Native-поле времени броска или nil; не прогноз момента взрыва |
| strength | Native-поле силы броска или nil |

Optional-поля читаются только при доступной schema. nil означает отсутствие данных. Не заменяйте его автоматически на false или 0 при принятии решения о броске.

## Владение командой

В create_move вызовите `grenades.claim()`. True разрешает для этого pending-запроса изменение grenade-углов и attack/attack2. False означает, что подходящая активная граната не найдена. Перед применением повторно проверяется тот же handle.

`cmd.set_angles({x=pitch,y=yaw,z=roll},visible)` ограничивает pitch диапазоном −89…89, нормализует yaw и обнуляет roll. При visible=true также меняется камера после успешного применения. Изменяется базовый grenade-ввод, а не произвольная shot history. Штатный AA отключается для успешно занятой grenade-команды.

`cmd.set_button(buttons.attack,true)` удерживает основную кнопку, attack2 — дополнительную. Комбинация кнопок влияет на игровой способ броска. Для отпускания задайте false; не путайте это с отменой уже выпущенной гранаты.

`grenades.cancel()` в create_move удаляет **весь ещё не применённый запрос этого скрипта**, включая оси и movement claims. Уже опубликованные команды не возвращаются назад. После вытаскивания чеки прекращение удержания может само привести к броску; после выпуска гранату отменить нельзя.

Claim действует одну команду. Он не выключает все native-режимы движения и не заменяет проверки ручного ввода в вашей автоматизации. При смене оружия/карты, смерти, ручном override, ошибке или выгрузке сценарий должен прекратить выдачу новых запросов.

## Готовый grenade helper

Скопируйте [grenade_helper.lua](examples/grenade_helper.lua) в папку Lua. В его контролах включите helper, выберите слот 1–16 и параметры jump/run/crouch/throw buttons.

1. Возьмите нужную гранату на нужной карте.
2. Отключите конфликтующие штатные movement-режимы и peek assistance.
3. При необходимости запишите точки подхода клавишей **F7**, не более 32.
4. Встаньте на позицию броска, выставьте углы и нажмите **F6**. Сохранятся карта, тип гранаты, origin, angles, route и выбранные параметры.
5. Отойдите к началу безопасного записанного пути. **F8** запускает подход, подготовку и отпускание либо отменяет текущий сценарий.

WASD, jump, Shift/Ctrl, кнопки мыши и заметное изменение камеры останавливают автоматизацию. Смена карты/оружия, отсутствие локального игрока и timeout 20 секунд также отменяют её. Надпись helper показывает текущую стадию или причину остановки.

Это последовательность approach → prime → prepare → release. Кнопки удерживаются на отдельных командах; release запрашивается позже по номеру команды. После отпускания helper освобождает следующую команду.

Подход использует line trace на высоте корпуса и короткие записанные точки. Это не навигация и не проверка объёма игрока: сложный проход, прыжок через препятствие или новая геометрия карты требуют проверки вручную. При стене или слишком большом перепаде высоты пример отменяется.

Записи хранятся через storage под lineups_v1; схема version=1. После изменения карты или физики снова проверяйте landing. Пример не предоставляет точную subtick-запись и не обещает одинаковый серверный результат на каждой версии игры.

## Наблюдаемые projectile и огонь

`grenades.observations(paths)` возвращает массив до 128 клиентских projectile/inferno. Это не список всех гранат на сервере. По умолчанию paths=false; true запрашивает также кэшированные траектории. Первый вызов может вернуть пустой массив до следующего обновления на игровом потоке. Для постоянного отображения вызывайте метод из paint. Штатные визуальные функции для Lua включать не нужно.

Данные снимка старше 250 мс не выдаются. Запрос продлевает сбор на 500 мс. После прекращения запросов сбор прекращается по истечении этого срока, если он не нужен другой функции. При смене карты кэш сбрасывается. Частота зависит от активных прогнозов; интервалы приведены ниже.

| Поле | Значение |
|---|---|
| id | Поколение записи кэша; лучше подходит для различения объектов, чем один index |
| index | Индекс сущности; может переиспользоваться |
| kind | hegrenade, flashbang, smokegrenade, molotov, decoy, inferno или unknown; летящие molotov/incendiary используют общий класс и имя molotov |
| item_id | 43–48 для определённого projectile; 0 для inferno/unknown |
| origin | Текущая наблюдаемая мировая позиция |
| velocity | Наблюдаемая скорость или nil |
| observed | true |
| age | Возраст от native spawn time, секунды, или nil |
| local_thrower | true, если thrower удалось разрешить в локального игрока; false также означает неизвестного владельца |
| effect_started | Наблюдается native-флаг взрыва/дыма, начало decoy либо это inferno |
| effect_ended | По доступным флагам, очагам или оценке длительности эффект завершён; сущность ещё может оставаться в кэше |
| opacity | Прозрачность штатного индикатора 0…1; при 0 запись не следует рисовать |
| geometry | nil либо `{kind="fire_points", points={...}, exact_damage_boundary=false}` |
| trajectory | nil либо [GrenadePath](TYPES.ru.md); только при запросе paths и доступных данных |
| trajectory_age | Возраст расчёта в секундах, отдельно от age самой гранаты |
| detonation_time | nil: точный будущий момент взрыва не предоставляется |

Generic grenade projectile без подтверждённого конкретного класса остаётся unknown. Не рисуйте для него придуманную иконку типа. При пересоздании кэша id меняется. Исчезновение записи не доказывает взрыв — объект мог стать недоступен клиенту.

Для inferno geometry.points содержит до 64 позиций **горящих** очагов из доступных полей schema. Пустой массив означает, что в корректно прочитанном наборе нет горящих точек; nil — данные недоступны. Это не готовый полигон урона. Штатная отрисовка строит сглаженный выпуклый контур вокруг кругов радиусом 60 единиц у очагов, с градиентом внутрь. Контур декоративный: может объединять разрывы и не учитывает стены; его нельзя считать точной границей урона.

initial_position и initial_velocity — доступные начальные данные полёта или nil. trajectory содержит полный кэшированный маршрут от этих данных. timer_remaining и timer_duration — оставшееся и полное время таймера или nil. Для HE используются доступные времена выпуска/детонации; для smoke — 20 с от эффекта, inferno — 7 с, decoy — 15 с от запомненного начала. Это визуальные оценки; изменения серверных правил могут менять фактическую длительность. Flash и летящий molotov таймер не получают.

Окончание эффекта отделено от удаления сущности: нулевой таймер, подтверждённое отсутствие горящих очагов, флаг взрыва или выключение уже начавшегося дыма запускают плавное исчезновение за 0.35 с. Исчезновение самой сущности также запускает fade. Штатный renderer сохраняет последнюю видимую геометрию на время fade. Lua observations после удаления сущности её не возвращает: для собственного исчезновения храните последнее наблюдение в скрипте. Пока завершённая сущность существует, effect_ended остаётся true, opacity доходит до 0 и индикатор повторно не появляется.

## Траектория и предпросмотр броска

`grenades.preview()` запрашивает и читает кэшированный предпросмотр гранаты в руках. Можно вызывать из paint. При первом запросе или отсутствии активной гранаты возможен nil с причиной. Результат содержит item_id и поля GrenadePath. Для броска используются углы камеры, проверенная точка глаз, скорость игрока, native throw velocity и сила броска. В первом лице точка камеры вычисляется из актуальной матрицы вида и проверяется относительно игрока. Для third person используется origin игрока плюс корректный view offset: отодвинутая камера не становится точкой выпуска. При недоступной native throw velocity используется стандартный профиль 750. Команда игрока не изменяется.

Для выбранных углов вызовите `grenades.predict_throw(angles, strength)` **в командном событии** и сохраните результат для paint. Strength: 1 для основной кнопки, 0 для дополнительной, 0.5 для обеих; допустимы промежуточные значения 0…1. Pitch ограничивается −89…89, yaw нормализуется, roll игнорируется. Метод проверяет фактическую гранату в руках и не требует claim, поскольку ничего не бросает.

`grenades.predict(origin, velocity, item_id, age)` также доступен только в командных событиях. Он рассчитывает движение от заданной мировой позиции со скоростью в единицах/секунду. item_id — 43…48; age — неотрицательные секунды с выпуска, по умолчанию 0. Для уже летящей гранаты передавайте её фактический age; не заменяйте неизвестный возраст нулём. Метод не запускает повторный player prediction и не записывает углы, кнопки или shot history.

| Поле GrenadePath | Значение |
|---|---|
| points | Последовательные мировые точки, включая начальную |
| bounces | Точки столкновений модели |
| end_pos | Последняя рассчитанная позиция |
| duration | Секунды от переданного состояния до конца расчёта; не полный возраст гранаты |
| valid | Есть завершённый маршрут или хотя бы две частичные точки; завершённый неподвижный маршрут может содержать одну точку |
| complete | Достигнуто условие завершения модели: detonation, stopped или contact_limit; не ошибка ресурса/трассировки |
| detonated | Достигнуто условие детонации **в прогнозе**, не факт взрыва в игре |
| reason | Причина завершения или недоступности |
| traces | Число попыток трассировки полёта; без предварительного sweep позиции броска |

Показывайте end_pos как предполагаемое место взрыва только при **valid=true, complete=true и detonated=true**. При stopped это остановка движения; при contact_limit — конец расчёта после более 20 шагов со столкновениями. Ни один из них сам по себе не означает взрыв. Для неполной траектории можно показать рассчитанные сегменты с подписью причины. Причины ошибок: invalid_input, collision_unavailable, collision_unavailable_or_budget, start_solid, invalid_collision, invalid_normal, tick_limit. Для броска возможны no_active_grenade, player_velocity_unavailable, player_eye_unavailable, throw_origin_unavailable_or_budget, throw_origin_start_solid и throw_origin_invalid_collision. При nil из preview причины snapshot_unavailable или preview_unavailable.

Модель использует шаг 1/64 с, hull 4×4×4, гравитацию sv_gravity×0.4, коэффициент отскока 0.45 и замедление на полу. При недоступных convar базовые значения: sv_gravity=800, уклон 30°. Для HE/flash проверяется превышение 1.5 с после восьми шагов задержки; для molotov/incendiary — уклон последнего контакта или превышение 2 с. Для smoke/decoy проверяется малая горизонтальная скорость через каждые 12 шагов, без обязательного контакта с полом. Поэтому вертикально падающий smoke может получить слишком ранний конец прогноза. Любая граната может завершить маршрут при малой общей скорости. Остановка HE не считается взрывом.

Счётчик duration начинается с нулевого шага, хотя движение на этом шаге уже рассчитано. Длительность и конец маршрута — результаты модели, не точные серверные данные. Материалы, движущиеся объекты, subtick, изменения convar/физики и версия игры могут менять результат. Сравните прогноз с реальным броском для каждого типа гранаты, включая движение и присед.

### Частота и лимиты

На все скрипты и штатные прогнозы вместе действует бюджет не более 1024 hull traces за окно 50 мс. После суммарных 2 мс внутри трассировок в этом окне новые traces отклоняются. Это ограничитель новых вызовов, а не гарантия времени кадра: уже начатый engine trace нельзя прервать. Один прогноз ограничен 1024 шагами и четырьмя контактами на шаг. Маркер отскока добавляется один раз на шаг со столкновениями.

Полный маршрут летящей гранаты рассчитывается из начальных данных и сохраняется до удаления наблюдения. Отсутствие начальных данных или исчерпание бюджета может оставить trajectory=nil; позиции продолжают обновляться. Нативная линия затухает за 0.5 с после завершения расчётного полёта/начала эффекта; исчезновение сущности имеет задержку 0.5 с перед затуханием. Предпросмотр получает приоритет перед расчётом летящих гранат. При неизменных входных данных незавершённый расчёт до 150 мс переиспользует готовые traces, включая начальную проверку точки выпуска. Изменение её позиции, направления или игрока требует нового начального sweep; смена скорости, оружия или convar сбрасывает соответствующую работу полёта. Предпросмотр плавно сводит точки при одинаковой топологии полного маршрута, после отпускания чеки скрывается на секунду. Частичная свежая линия отображается без конечного маркера. При отсутствии свежих точек последний полный предпросмотр удерживается до 150 мс.

Минимальный интервал обновления наблюдений — 50 мс, при включённых траекториях — 16 мс, при предпросмотре или Lua-запросе paths=true — 8 мс. Бюджет и частота кадров могут снижать фактическую частоту. Не перебирайте сотни углов на каждой команде. Для обычной визуализации используйте кэшированные preview/observations.

Пример: [grenade_trajectory.lua](examples/grenade_trajectory.lua). Режим кэша не делает traces из paint; режим выбранных углов показывает predict_throw из create_move. [Радар](RADAR.ru.md) использует те же наблюдения.

## Штатные переключатели

В Visuals, при включённом общем ESP, доступны **Grenade Icons**, **Grenade Trajectories**, **Grenade Throw Preview**, **Molotov Area**. Grenade Trajectories также включает обновляемый предпросмотр гранаты в руках: удерживайте бросок и поворачивайте камеру. Grenade Throw Preview позволяет включить его отдельно от летящих гранат. Эти основные переключатели по умолчанию выключены. Они включают наблюдение/отрисовку и не запускают автоматический бросок.

Для траекторий настраиваются цвет, толщина, радиус Gaussian bloom, квадратные маркеры отскоков/конца и отображение только своих полётов. У предпросмотра нет фильтра чужих гранат — он всегда относится к вашим рукам. **Grenade Display** выбирает круговые иконки или текст; **Grenade Timers** включает кольцо/число обратного отсчёта. Цвета типов и таймера задаются отдельно, по умолчанию белые. Сохранённые в существующем конфиге цвета сохраняются. У Molotov Area настраиваются ширина и прозрачность внутреннего градиента. Подписи и числа используют штатные шрифты Skeet.

Значения по умолчанию: **Trajectory Thickness — 0.7**, **Trajectory Bloom Radius — 16**, **Endpoint Size — 4**, **Bounce Size — 2**. Настройки, уже сохранённые в конфиге, сохраняются при обновлении.

Положение штатных иконок плавно интерполируется между наблюдениями, без округления движущегося глифа до целого пикселя. Lua origin остаётся исходной наблюдаемой позицией: сглаживание renderer не меняет игровые данные, траекторию или физику.

## Иконки и радиусы

В paint `render.grenade_icon(kind)` принимает hegrenade, flashbang, smokegrenade, molotov, incgrenade, decoy. Успех: texture handle, width, height. Недоступность: nil, reason. Неизвестное имя вызывает ошибку.

```lua
local icon, attempted
events.on("paint", function()
    if not attempted then
        attempted = true
        icon = render.grenade_icon("hegrenade")
    end
    if icon then render.texture(icon, 40, 200, 32, 32) end
end)
```

Handle принадлежит скрипту и используется обычным render.texture. Один raster каждого вида кэшируется. При неудаче храните признак попытки, а не повторяйте загрузку каждый кадр.

`render.circle_3d`, `circle_filled_3d` и `circle_fade_3d` позволяют показать выбранный радиус. Он задаётся в игровых единицах и сам по себе не учитывает стены, форму распространения огня и реальный урон. [grenade_warning.lua](examples/grenade_warning.lua) показывает иконки, доступные очаги и настраиваемый приблизительный круг вокруг наблюдаемой позиции; для inferno использует molotov.
