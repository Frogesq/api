# Среда выполнения

## Язык и доступные библиотеки

Встроен Lua 5.5.0. Проверка: `api.lua` возвращает `Lua 5.5`, `api.version` — `3`, `api.script` — имя текущего скрипта. Это не LuaJIT; `jit` и LuaJIT-библиотека `bit` отсутствуют. Для целочисленных масок используйте операторы Lua `&`, `|`, `~`, `<<`, `>>`.

`api.capabilities()` возвращает отдельные признаки возможностей:

| Поле | Сейчас | Смысл |
|---|---|---|
| command_requests | true | Отложенные запросы create_move |
| prediction_snapshot | true | Чтение штатного результата |
| grenade_control | true | Проверяемый grenade claim |
| grenade_observations | true | Наблюдение projectile/inferno |
| grenade_icons | true | Получение native-иконок |
| prediction_simulate | false | Произвольная симуляция не предоставлена |
| grenade_trajectory | true | Приблизительная симуляция гранаты с hull traces и отскоками |
| inferno_geometry | true | Позиции горящих очагов при доступной schema; не точная граница урона |
| radar_snapshot | true | Общий снимок игроков/гранат и проекция на радар |
| rage_control | false | Управление аимботом не предоставлено |

True означает наличие API, а не гарантированное наличие данных в конкретном кадре: результат всё равно может быть nil, например вне карты.

Доступны базовые функции языка, `table`, `string`, `math`, `utf8` и API Skeet. Из базового окружения убраны `load`, `loadfile`, `dofile`, `collectgarbage`, `pcall`, `xpcall`. Не открыты `io`, `os`, `package`, `debug`, `coroutine`, `socket`, `http`. `require` принимает только `ffi` и `cffi`, возвращая один встроенный модуль. Установка обычного Lua-пакета в соседнюю папку не делает его доступным через require.

## Загрузка и время жизни

При включении создаётся состояние Lua и один раз исполняется верхний уровень файла. Здесь объявляют функции, создают контролы и окна, подписываются на события, готовят звук и материалы. Затем вызываются зарегистрированные обработчики. Сам факт регистрации не выполняет обработчик немедленно.

Каждый скрипт владеет своими подписками, контролами, окнами, настройками override и handles ресурсов. Числовой handle текстуры или материала не является адресом памяти. Не используйте handle, который принадлежит другому скрипту, и не сохраняйте его в storage для следующего запуска.

При штатной выгрузке вызывается `shutdown`, освобождаются принадлежащие скрипту объекты и сохраняются данные. На аварийном пути вызов `shutdown` не гарантируется. Native-клиент через FFI должен иметь собственную корректную схему остановки и владения памятью.

## Когда все скрипты выключены

После завершения выгрузки последнего скрипта командные и кадровые Lua-обработчики пропускаются до блокировки Lua, создания таблиц событий и копирования prediction. Игровые события не разбираются для Lua и не накапливаются для следующего включения. Счётчик render.frame_count продолжает считать paint-проходы.

Выгрузка освобождает командное владение скрипта; после последней Lua очищаются снимок prediction, права bhop/strafe/grenade и очередь событий. Удаление Lua-кейбинда не сбрасывает историю удерживаемых клавиш и toggle-состояние штатных биндов.

Это не откат любых последствий скрипта. `settings.set` сохраняет записанные настройки, уже выполненная команда консоли не отменяется, выпущенная граната не возвращается. Произвольные записи памяти, патчи и фоновые задачи внешней DLL через FFI автоматически не восстанавливаются. Для временных настроек используйте `settings.override`, для внешних ресурсов реализуйте корректный shutdown. Выключенный ранее выполнявшийся скрипт и скрипт, который вообще не запускали, могут оставить разное состояние игры.

Само присутствие интерфейса оставляет небольшие проверки в native-путях, а наблюдения за гранатами поддерживаются отдельным кэшем сущностей. Отсутствие Lua-записей в команду не является измерением FPS, времени тика или качества стрельбы.

## Ошибки

Неправильные типы, недопустимая фаза или чужой handle обычно вызывают Lua-ошибку. Ожидаемая недоступность данных часто возвращает `nil`, а ресурсные функции — `nil, reason` или `false, reason`. Проверяйте контракт конкретной функции: одинаковое количество результатов у всех API не предполагается.

Необработанная ошибка callback отключает скрипт и записывается в журнал Lua. Ещё не применённые командные запросы этого dispatch отбрасываются. Записи настроек, вывод консоли, рисование и эффекты FFI не являются транзакцией и автоматически не откатываются.

Для локальной обработки ошибки используется `api.protect`:

```lua
local ok, err, result = api.protect(function()
    return 6 * 7
end, {instructions=10000, time_ms=5})

if ok then
    client.log("Result", result)
else
    client.log_level("warning", err)
end
```

При успехе возвращаются `true, nil`, затем все результаты функции, включая nil. При обычной ошибке — `false, текст ошибки`. При превышении бюджета третьим результатом приходит таблица `{kind, scope, retryable}`; `err` точно равен `budget_exceeded`. Не считайте произвольную строку с таким текстом достоверной информацией о native-сбое.

Внутри защищённого блока ошибка отменяет его накопленные командные изменения. Остальные побочные эффекты сохраняются. Ошибка выделения Lua-памяти остаётся фатальной. Долгий native-вызов нельзя принудительно остановить обычным Lua hook.

## Бюджеты и производительность

| Ограничение | Значение |
|---|---|
| Исходник скрипта | 512 КиБ |
| Память Lua allocator одного скрипта | 32 МиБ |
| Обычный dispatch | 20 000 000 VM-инструкций, 250 мс |
| Загрузка | До 5 секунд |
| Работа host API и преобразований за dispatch | 262 144 учётных единицы |
| `api.protect` по умолчанию | 1 000 000 инструкций, 25 мс |
| Максимальные запрашиваемые пределы protect | 20 000 000 инструкций, 250 мс; внешний бюджет всё равно действует |
| Зарегистрированные callbacks | 128 на скрипт, включая callbacks XUI |
| Контролы `ui.create` | 128 на скрипт |
| Окна | 8 на скрипт |
| Одновременно включённые скрипты | 64 |
| Сериализованный storage | 64 КиБ на скрипт |

Это аварийные пределы, а не рекомендуемое время на тик. Уже несколько миллисекунд тяжёлого кода в каждом кадре могут быть заметны. Счётчик VM-инструкций приблизителен. Native-память FFI и графические ресурсы не входят целиком в 32 МиБ Lua allocator.

`api.budget()` показывает текущие остатки и `recovering`. Если `recovering=true`, завершайте callback: повторение исчерпанной работы не выдаёт новый полный бюджет. `retryable` означает только наличие бюджета родителя, а не обещание, что повторный расчёт успеет закончиться.

`client.stats()` возвращает время, инструкции, API-вызовы, native work, память, число завершённых вызовов и предыдущий снимок `last`. `time_ms` не является чистым CPU-временем или замером GPU. `client.time()` — монотонные секунды, а не игровое время; `client.frametime()` — длительность кадра.

Кэшируйте текстуры, шрифты и подготовленный звук. Дробите большие Lua-расчёты между callbacks с сохранением индекса в локальной переменной. Не создавайте новые контролы, подписки и уникальные ресурсы каждый кадр.
