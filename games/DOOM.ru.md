# Doom через Lua FFI

Скрипт [doom.lua](doom.lua) использует внешний PrBoom libretro core: получает видео, отправляет звук и преобразует клавиши через FFI. Отдельного Doom API в Skeet не требуется. Native core должен соответствовать x64-процессу.

## Размещение файлов

```text
%LOCALAPPDATA%\skeet\
  doom.lua
  doom\
    prboom_libretro.dll
    prboom.wad
    doom1.wad
    PrBoom-COPYING.txt
```

`doom.lua` берётся из этой папки документации. DLL и WAD — отдельные внешние файлы, не создаются Lua-скриптом и не входят автоматически в комплект обычной документации. Закреплённые имена, размеры, SHA-256 и сведения об источниках находятся в [doom-assets.json](doom-assets.json). Nightly-ссылка может со временем выдавать другой core; не считайте его идентичным только по совпадению имени файла.

`doom1.wad` — shareware-вариант. Для дополнительных эпизодов разместите собственный подходящий `doom.wad` или `doomu.wad`, выберите его в контролах и перезагрузите скрипт. `prboom.wad` — отдельный ресурс core, он не заменяет игровой IWAD. Для сохранений core получает папку `doom/saves`. Сохраняйте лицензию вместе с распространяемым core.

## Запуск и управление

1. Включите doom.lua в меню Lua.
2. Проверьте выбор IWAD и видимость окна.
3. Нажмите **P**. При открытом меню запрос запуска запоминается; закройте меню, чтобы продолжить. Повторное P отменяет запрос/ставит на паузу.
4. В меню Doom нажмите Escape → New Game.

| Клавиши | Действие |
|---|---|
| WASD | Движение |
| Q/E или стрелки | Поворот |
| Ctrl / левая кнопка мыши | Огонь в Doom |
| Space / правая кнопка мыши | Use/дверь |
| Shift | Бег |
| Tab | Карта |
| 1–7 | Оружие |
| Escape / Enter | Меню / подтверждение |
| F2 / F3 | Сохранение / загрузка |
| P | Пауза и возврат управления |

Потеря фокуса и открытое меню Skeet приостанавливают активную игру. Окно можно перетаскивать при открытом меню; масштаб и громкость доступны в контролах. До запуска выводится предварительный кадр. Если core не предоставляет видео, смотрите статус в окне и журнал Lua.

## Взаимодействие с CS2

Перед тестом выключите штатные боевые функции, peek assistance и конфликтующее движение в меню Skeet. Checkbox `Block game movement while playing` заменяет только вход движения в create_move. Он **не блокирует стрельбу CS2**, не захватывает аимбот и не отменяет обычные действия игры по клавишам. Для теста выбирайте состояние, где этот ввод не мешает активной игре.

Core работает синхронно в графическом callback. Его производительность, звук и корректность конкретной native DLL проверяются запуском пользовательской сборки; успешная проверка Lua-синтаксиса этого не подтверждает. Скрипт удерживает callbacks и буферы до остановки core и ограничивает запуск второй копии именованным mutex.

Если окно остаётся пустым, проверьте четыре внешних файла, их разрядность/контрольные суммы, выбранный IWAD, статус паузы и сообщения журнала. Не заменяйте отсутствующий callback произвольной заглушкой в FFI-объявлении.
